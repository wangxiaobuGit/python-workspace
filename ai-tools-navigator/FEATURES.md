### 3. GitHub热榜模块

#### 核心功能
- **自动爬虫**: 基于GitHub API的智能爬虫
- **定时更新**: APScheduler定时任务，每6小时更新
- **数据缓存**: 防止重复抓取，提高性能
- **手动更新**: 管理后台支持手动刷新数据

#### 技术特性
- **API限制处理**: 智能请求频率控制
- **错误处理**: 完善的异常处理机制
- **数据持久化**: JSON格式本地存储
- **多语言支持**: 支持多种编程语言项目

## 🚀 部署说明

### 环境要求
```bash
Python 3.8+
Flask 2.3.3
APScheduler 3.10.4
requests 2.31.0
beautifulsoup4 4.12.2
```

### 启动命令
```bash
cd ai-tools-navigator
pip install -r requirements.txt
python app.py
```

### 访问地址
- **主页**: http://localhost:12001/
- **管理后台**: http://localhost:12001/admin
- **API文档**: http://localhost:12001/api/stats
